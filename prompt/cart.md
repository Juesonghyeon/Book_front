# 1. 목적
- 장바구니 등록 기능
- 장바구니 리스트 화면 이동

# 2. 기능구현

## 2.1 장바구니 등록
- 기능에서 장바구니 버튼을 누르면 서버 API 를 호출하여 해당 책을 장바구니에 등록
- 해당 기능은 로그인 시에만 가능
- 비로그인 시에는 '해당기능은 로그인이 필요합니다. 로그인하시겠습니까?' 출력
- 비로그인 시 장바구니 요청 데이터를 저장
- 로그인 후 요청페이지로 복귀 후 장바구니 등록 api 실행
- 장바구니 등록 후 '장바구니에 등록되었습니다. 장바구니로 이동하시겠습니까?' 출력과 함께 이동 또는 쇼핑계속하기 버튼 노출
- 쇼핑 게속하기면 현재 페이지 유지

### 2.1.1 API 연동
- end-point : /api/v1.carts
- method : POST
- 파라미터 양식 : application/json
- 파라미터 :
    ```
    {
        bookId : BOOK001,
        quantity : 1
    }
    ```
- 결과 :
    - 성공 시 : { "code" : 200, "message" : "장바구니 등록이 되었습니다."}
    - 실패 시 : { "code" : 500, "message" : "장바구니 등록이 실패되었습니다."}

### 2.1.2 UI 구성
- API 만 필요 해당 기능에 UI 필요 없음

## 2.2 장바구니 리스트
- 장바구니 담긴 책 리스트를 보여주는 페이지
- 로그인한 사용자만 접근 가능
- 비로그인시 페이지로 이동
- 장바구니가 비어 있을 경우, 장바구니에 담긴 상품이 없습니다. 표시
- 장바구니가 비어 있을 경우, 구매버튼을 누르면 선택된 상품이 없습니다 출력

### 2.2.1 서버 API 연동
- end-point : /api/v1.carts
- method : GET
- 파라미터 양식 : 없음
- 파라미터 :
    ```
    {
        "code" : 200,
        "data" : [
            {
                "bookId" : "BOOK001",
                "title" : "클린코드",
                "author" : "TOM",
                "quantity" : 1,
                "originalPrice" : 30000,
                "salePrice : 3000,
                "imageUrl": ""
            }
        ]
    }
    ```
